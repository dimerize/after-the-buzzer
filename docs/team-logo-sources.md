# Team logo provenance

These are the primary logos listed in Chris Creamer's SportsLogos.Net [2007–2008 NBA season catalog](https://www.sportslogos.net/teams/list_by_year/62008/2008-NBA-Logos-By-Year/), checked 2026-10-10. The catalog's ending-year URL is **2008**, not 2007. Where its images had opaque backgrounds, transparent originals of the same historical marks were obtained from the asset sources linked below. This is a fixed historical theme, not a claim that current games took place in 2007–08.

The source page for each file below independently dates the selected primary mark to a range containing 2007–08. Toronto retains the purple dinosaur; Denver and Minnesota retain the designs that ended after 2007–08. Atlanta, Charlotte, New Orleans and Washington use the marks listed as new for that season.

Current abbreviations remain visible in the app. Historical logo tooltips explicitly say New Jersey Nets for BKN, Seattle SuperSonics for OKC, New Orleans Hornets for NOP, and Charlotte Bobcats for CHA. NJ/NJN/BRK, SEA, NO/NOH/NOK, CHO and common provider aliases resolve to the same period assets. Unknown identities remain text-only.

## File-level sources

Local files are under `public/team-logos/`. Source-provided PNG/GIF/SVG assets were fetched from the linked archive pages, decoded or rasterized with Sharp and stored as compact PNG thumbnails, preserving proportions and source transparency. No logo was redrawn, recolored, generated by AI, or replaced with a current mark. Opaque source canvases were replaced with published transparent assets, not erased from the artwork. The catalog tests decode all 30 images and check dimensions, transparent corner pixels and transparent pixel coverage. All marks were also inspected on navy to distinguish legitimate white logo details from an unwanted background rectangle.
