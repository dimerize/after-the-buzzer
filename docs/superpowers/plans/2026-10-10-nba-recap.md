# NBA Recap Implementation Plan

> **For agentic workers:** Execute the bounded tasks below in parallel where interfaces permit, then review and verify the integrated app. Steps use checkbox syntax for tracking.

**Goal:** A working personal NBA PWA with honest live-data handling and a deployable scheduled backend.
**Architecture:** React reads a typed dashboard API. A Cloudflare Worker normalizes ESPN data, computes stories, stores preferences and editions in D1, and supports authenticated refresh and scheduled publication.
**Tech Stack:** TypeScript, React, Vite, Cloudflare Workers/D1, Vitest.
**Spec:** docs/superpowers/specs/2026-10-10-nba-recap-design.md

## Global Constraints

- Budget below $10/month; optional AI application budget $3/month.
- Credentials stay server-side; deployment requires owner authentication.
- Demo data must be labeled; never claim records without evidence.
- Five favorites and midnight/date handling from the spec are mandatory.

## Review Focus

- Empty, partial, malformed, delayed and unreachable provider responses must never become fabricated completed recaps.
- Overnight dates and daylight-saving time must not lose late games.
- Saved preferences need validation and unauthorized writes must fail.
- DNP, zero minutes and tied leaders must have correct treatment.
- Demo and partial history must never contaminate real archives or season claims.
