# After the Buzzer

Build a personal phone-first NBA reader for bedtime and nights out, with an expected operating budget below $10/month. The user approved implementation of the proposal in chat. Favorites are Victor Wembanyama, LeBron James, Keaton Wagler, Dylan Harper, and Stephon Castle. Confirm provider identities; unresolved names remain visible without invented data.

Tonight contains a short ranked recap, favorites with full stats, league leaders, exceptional performances, and clearly marked unfinished games. Archive, saved player tiers, bedtime preferences, score hiding, and tracked season stats are included. Sample mode must be labeled throughout; no invented historical claims or unverified current stats. Stable player IDs anchor the watchlist. All computation is deterministic; optional AI may polish verified facts with an application spending guard of $3/month and a template fallback.

Implementation decision: React/TypeScript frontend and one Cloudflare Worker with D1 and scheduled triggers. This reduces the prior Python/GitHub/Worker split and keeps scheduled data collection independent of the laptop. Build and verify locally before connecting external accounts. Credentials are server-side only. Private single-owner authentication is required before deployment. Browser receives only a secure session cookie, never an upstream API credential.

Bedtime defaults to 23:30 America/New_York. Preserve the basketball date through overnight games; later refreshes finalize the same date. Favorites always appear, including clear DNP/no-game states. Live alerts are optional and deduplicated, quiet hours respected. Push requires browser permission and VAPID configuration. Persist archive only from real provider data. Trackers describe the actual stored date range and competition, never imply full-season coverage from partial history.

Design revision explicitly requested by the user: base the entire UI on NBA 2K7 for Xbox 360 and PS3. The previous modern navy reader design is superseded. Use the original Association roster interface as a concrete visual reference: nighttime skyscrapers with cyan office windows, red horizontal light streaks, white heavy italic titles, layered glossy blue/chrome panel borders, translucent black interiors, silver statistic cells, condensed white roster text and a royal-blue selected row. Use a centered game-menu layout, compact status/profile panels, dense useful box-score information and actionable controller-style navigation. No SaaS sidebar, marketing hero or decorative court diagram. Carry the same treatment through all four screens, authentication, loading and dialogs. Preserve legible phone layouts, keyboard access, explicit data states and the existing functionality. The city background is original SVG artwork, not a copied game asset; the app remains branded After the Buzzer.
